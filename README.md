# Выставка собак

Веб-приложение для организаторов выставки собак: учёт собак-участников,
экспертов, рингов, медалей и расписания пород.

Курсовой проект по дисциплине «Создание программного обеспечения».

---

## Стек технологий

- **Python** 3.12+
- **Django** 5.2 — веб-фреймворк
- **Django REST Framework** — REST API
- **PostgreSQL** — база данных
- **Bootstrap 5** — фронтенд-фреймворк
- **drf-spectacular** — генерация Swagger-документации
- **pytest** + **pytest-django** — автотесты

---

## Возможности

### Учёт данных
- Собаки: кличка, порода, клуб, хозяин, возраст, родословная, прививки
- Хозяева: ФИО, паспортные данные
- Породы и кинологические клубы
- Эксперты: ФИО, специализация по породе, ринг, клуб
- Ринги: номер, адрес, клуб
- Медали: тип (золото/серебро/бронза), дата награждения
- Расписание: распределение пород по рингам во времени

### Функциональность
- Полный CRUD для всех сущностей
- Связанная навигация: собака → хозяин → порода → эксперты → ринг
- Роли пользователей (организатор, председатель клуба, эксперт)
- Отстранение собак от участия
- Сводная статистика: медали по клубам, рекордсмены по породам
- REST API с интерактивной документацией Swagger
- Поиск и фильтрация во всех разделах

## Установка и запуск

### Требования
- Python 3.12 или выше
- PostgreSQL 14 или выше
- Git

### Шаги

**1. Клонировать репозиторий:**

```bash
git clone https://github.com/username/dogshow.git
cd dogshow
```

**2. Создать и активировать виртуальное окружение:**

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
```

**3. Установить зависимости:**

```bash
pip install -r requirements.txt
```

**4. Создать файл `.env` в корне проекта:**

```
DJANGO_SECRET_KEY=your-secret-key-here
DJANGO_DEBUG=True
DB_NAME=dogshow
DB_USER=postgres
DB_PASSWORD=your-postgres-password
DB_HOST=127.0.0.1
DB_PORT=5432
```

**5. Создать базу данных в PostgreSQL:**

```sql
CREATE DATABASE dogshow WITH ENCODING 'UTF8';
```

**6. Применить миграции:**

```bash
python manage.py migrate
```

**7. Создать суперпользователя:**

```bash
python manage.py createsuperuser
```

**8. (Опционально) Загрузить тестовые данные:**

```bash
python manage.py loaddata initial_data
```

**9. Запустить сервер:**

```bash
python manage.py runserver
```

Приложение доступно по адресу: **http://127.0.0.1:8000/**

## Использование

### Вход в систему

Откройте `http://127.0.0.1:8000/`. Будет перенаправление на страницу входа.
Введите логин и пароль суперпользователя, созданного на шаге 7.

### Основные разделы

| Раздел | URL | Описание |
|---|---|---|
| Главная | `/` | Обзор системы и быстрые ссылки |
| Участники | `/catalog/participants/` | Собаки, хозяева, породы, клубы |
| Эксперты и ринги | `/catalog/exhibitions/` | Эксперты, ринги, расписания |
| Медали | `/catalog/medals/` | Все медали, сводки по клубам, рекордсмены |
| Админка Django | `/admin/` | Управление всеми данными |
| Swagger | `/api/docs/` | Документация REST API |

### Связанная навигация

Из любой сущности можно перейти к связанным объектам:
- Собака → хозяин → все его собаки
- Собака → порода → все собаки породы, эксперты по породе
- Собака → клуб → ринги, собаки, эксперты клуба
- Эксперт → ринг → расписание и другие эксперты

## REST API

### Базовый URL

```
http://127.0.0.1:8000/api/v1/
```

### Авторизация

Все эндпоинты требуют аутентификации. Используется **Basic Auth** или **Session Auth**.
Для тестирования удобно использовать Swagger UI: `/api/docs/`.

### Ресурсы

| Ресурс | URL |
|---|---|
| Породы | `/api/v1/breeds/` |
| Клубы | `/api/v1/clubs/` |
| Хозяева | `/api/v1/owners/` |
| Собаки | `/api/v1/dogs/` |
| Эксперты | `/api/v1/experts/` |
| Ринги | `/api/v1/rings/` |
| Медали | `/api/v1/medals/` |
| Расписания | `/api/v1/schedules/` |

### Кастомные действия

| Действие | URL |
|---|---|
| Отстранить собаку | `POST /api/v1/dogs/{id}/disqualify/` |
| Восстановить собаку | `POST /api/v1/dogs/{id}/restore/` |
| Сводка медалей по клубам | `GET /api/v1/medals/by_club/` |

### Пример запроса

```bash
curl -u admin:password http://127.0.0.1:8000/api/v1/dogs/
```

Ответ:

```json
[
  {
    "id": 1,
    "name": "Рекс",
    "breed": 1,
    "breed_name": "Немецкая овчарка",
    "club_name": "Верный друг",
    "owner_name": "Иванов Иван Иванович",
    "age": 4,
    "pedigree_number": "РКФ-001-2020",
    "is_disqualified": false,
    "medals_count": 2
  }
]
```
